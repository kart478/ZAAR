COMMUNITAS Authentication Flow Test
=====================================

✅ FRONTEND PAGES CREATED:
- /auth/signup - Sign up with email + password
- /auth/signin - Sign in with OTP (primary) + password (optional)
- /auth/verify - Verify 6-digit OTP code

✅ BACKEND OTP ENDPOINTS:
- POST /api/v1/otp/request-code - Request OTP code
- POST /api/v1/otp/verify-code - Verify OTP code
- POST /api/v1/otp/resend-code - Resend OTP code

- OTP input with auto-advance and paste support
- 60-second resend cooldown
- 3 attempt limit per code
- 10-minute code expiration
- JWT tokens with refresh token (httpOnly cookie)
- Protected routes with automatic redirect
- Auth context with state management
- Loading states and error handling

✅ API INTEGRATION:
- Auto-refresh on 401 errors
- Secure token storage
- Consistent error messages
- Success toasts and notifications
